# Prepare evidence (2026-09-25)

The fixed corpus in `cases.json` contains 120 distinct legal 3-CNF inputs: 20 hand-designed edge cases and 100 seeded cases (`1000..1099`) regenerated by `generate_cases.py`. Variable counts are 0:1, 1:6, 2:36, 3:23, 4:22, 5:32. Clause counts range from 0 to 16. Independent labels give 108 satisfiable and 12 unsatisfiable formulas. Edges include empty formulas, forced literals, contradictions, tautologies and unused variables.

`check.py` uses the locked Python Z3 binding 4.16.0.0. The source encoding adds one Boolean disjunction per clause. Its returned assignments are checked directly against all input clauses. For all 120 cases, exhaustive truth-table search independently confirms the SAT/UNSAT status; an inconclusive Z3 status raises an error. `NO-SOLUTION` is accepted only after a conclusive UNSAT result.

The target oracle enumerates every nonempty, all-one rectangle with contiguous integer row/column intervals. A Boolean selection variable is constrained to cover every one cell with at most `K` selected rectangles. Every cover induces such a selection, and every selected set satisfying the constraints is an exact cover because only all-one rectangles are enumerated. A returned cover is independently checked cell by cell. Z3 UNSAT alone licenses `NO-SOLUTION`; unknown is an error. The oracle can enumerate two different selected sets but does not promise two geometrically distinct covers for every instance. Enumeration is exponential in target dimensions and is intended only for finite small targets.

Run from repository root:

```sh
uv sync --locked
uv run --locked python campaigns/three-sat-rectilinear-picture-compression/work/check.py --self-test
```
